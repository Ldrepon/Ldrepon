# Design System: Workout Tracker

## Theme Concept
"Energetic Dark Mode". A sleek, dark interface with vibrant accents to inspire activity.

## Color Palette
- **Background**: `#121212` (Almost Black)
- **Surface**: `#1E1E1E` (Dark Grey - Cards/Modals)
- **Primary**: `#2563EB` (Electric Blue - Actions)
- **Secondary**: `#10B981` (Neon Green - Success/Progress)
- **Error**: `#EF4444` (Red - Destructive)
- **Text Primary**: `#FFFFFF` (White)
- **Text Secondary**: `#A1A1AA` (Light Grey)

## Typography
- **Font Family**: 'Inter' or System Default Sans-Serif.
- **Headings**: Bold, generous letter spacing.
- **Body**: Regular, readable size (16sp).

## UI Components
- **Cards**:
    - Radius: `16.0`
    - Shadow: `BoxShadow(color: Colors.black12, blurRadius: 10, offset: Offset(0, 4))`
    - Padding: `16.0`
- **Buttons**:
    - Height: `50.0`
    - Radius: `12.0`
    - Style: Flat with gradient or solid primary color.
- **Inputs**:
    - Filled: `#27272A`
    - Border: None (until focused).
    - Radius: `12.0`
